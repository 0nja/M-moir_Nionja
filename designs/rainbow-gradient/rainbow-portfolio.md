# Rainbow Portfolio

## Intent
Présenter un portfolio de créatif ou designer avec une identité colorée et dynamique.

Catégorie : Arc-en-ciel & Dégradés. Ton : portfolio, arc-en-ciel, créatif, coloré, artiste.

## Style
- Fond sombre avec projets présentés en cards avec bordures rainbow
- Curseur personnalisé avec traînée colorée
- Texte nom/rôle en dégradé complet du spectre
- Filtres de catégorie avec couleur propre par catégorie

## Colors
- Mode: dark
- Primary: #FF3366
- Secondary: #FFD700
- Background: #0A0A0A
- Surface: #141414
- Text: #FFFFFF
- Text Muted: #888888
- Border: #222222
- Background treatment: plain

## Typography
- Heading font: Outfit
- Body font: Inter
- Hero: 80px, weight 800, tracking -3px
- H2: 32px, weight 700, tracking -1px
- Body: 16px, line-height 1.6
- Case: none
- Détail: Typographie large et impactante.

## Layout
- Container: 1280px
- Hero: centered
- Section principale: gallery
- Espacement entre sections: 100px entre sections
- Grille: grille de projets en 2 colonnes

## Spacing & Shape
- Border radius: 12px
- Borders: 1px solid #222222
- Shadows: 0 20px 40px rgba(0,0,0,0.6)

## Animation
- Load: slide-in de la gauche
- Hover: bordure rainbow sur les cartes de projet
- Scroll: parallaxe sur le nom en hero

## Components
- Hero avec nom en dégradé animé
- Navigation avec indicateur de section coloré
- Grille de projets avec bordures rainbow au hover
- Filtres par type avec couleur spectrales
- Footer minimaliste

## Sections Order
1. Hero avec nom en dégradé animé
2. Navigation avec indicateur de section coloré
3. Grille de projets avec bordures rainbow au hover
4. Filtres par type avec couleur spectrales
5. Footer minimaliste

## Do / Don't for AI
**Do:**
- Dégradé animé uniquement sur le nom et les bordures hover
- Fond très sombre pour le maximum de contraste
- Chaque catégorie de projet = une couleur du spectre

**Don't:**
- Pas de fond blanc ou gris clair
- Pas de typography colorée sur les descriptions de projet
- Ne pas animer trop d'éléments simultanément

## Responsive
Mobile : hero 48px, projets en 1 colonne.
