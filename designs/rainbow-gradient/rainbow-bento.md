# Rainbow Bento Grid

## Intent
Présenter des fonctionnalités ou du contenu avec une identité visuelle forte et joyeuse.

Catégorie : Arc-en-ciel & Dégradés. Ton : bento, arc-en-ciel, grille, coloré, vivant.

## Style
- Chaque carte bento a un dégradé unique tiré du spectre
- Fond blanc, texte foncé sur les cartes colorées
- Layout bento asymétrique (grande carte + petites)
- Transitions douces au survol

## Colors
- Mode: light
- Primary: #FF3366
- Secondary: #0090FF
- Background: #FFFFFF
- Surface: #F5F5F5
- Text: #FFFFFF
- Text Muted: #555555
- Border: #EEEEEE
- Background treatment: plain

## Typography
- Heading font: Outfit
- Body font: Inter
- Hero: 56px, weight 800, tracking -1px
- H2: 28px, weight 700, tracking 0
- Body: 16px, line-height 1.6
- Case: none
- Détail: Titres de cartes en blanc sur fond coloré.

## Layout
- Container: 1100px
- Hero: centered
- Section principale: bento
- Espacement entre sections: 80px entre sections
- Grille: bento 4 colonnes, rows auto

## Spacing & Shape
- Border radius: 20px
- Borders: aucune
- Shadows: 0 10px 30px rgba(0,0,0,0.1)

## Animation
- Load: scale up de chaque carte en décalé
- Hover: carte scale 1.02
- Scroll: reveal progressif

## Components
- Hero centré (fond blanc, titre foncé)
- Grande carte bento : rouge → orange
- Carte bento : jaune → vert
- Carte bento : vert → bleu
- Carte bento : bleu → violet
- Carte bento : violet → rose

## Sections Order
1. Hero centré (fond blanc, titre foncé)
2. Grande carte bento : rouge → orange
3. Carte bento : jaune → vert
4. Carte bento : vert → bleu
5. Carte bento : bleu → violet
6. Carte bento : violet → rose

## Do / Don't for AI
**Do:**
- Chaque carte = une couleur du spectre
- Texte blanc sur fond coloré pour le contraste
- Rayons de 20px constants

**Don't:**
- Pas de fond sombre global
- Pas de dégradé unique répété sur toutes les cartes
- Ne pas mélanger fond coloré et fond blanc dans la même ligne bento

## Responsive
Mobile : cartes empilées en pleine largeur.
