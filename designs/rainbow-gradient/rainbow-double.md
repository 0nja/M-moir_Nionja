# Double Arc-en-ciel

## Intent
Un univers créatif et harmonieux basé sur des arcs-en-ciel SVG croisés en arrière-plan et un menu de navigation masqué.

Catégorie : Arcs & Demi-cercles. Ton : arc-en-ciel, double, diagonal, sidebar, burger, svg.

## Style
- Fond dégradé dans des tons terre/pétrole clairs
- Deux ensembles d'arcs-en-ciel en SVG placés dans les coins opposés
- Sidebar sombre qui apparaît sur le clic d'un bouton burger
- Bouton d'action rouge vif stylisé

## Components

## Sections Order
1. Bouton burger avec animation CSS des barres
2. Sidebar de navigation avec effet de flou
3. 2 groupes de tracés SVG formant des arcs diagonaux
4. Contenu central textuel avec CTA

## Do / Don't for AI
**Do:**
- Utiliser du SVG pur pour dessiner les arcs en diagonale
- Préserver l'opacité (0.7) et les z-index pour le background
- Lier le burger menu à l'ouverture de la sidebar via CSS ou JS

**Don't:**
- Ne pas utiliser d'images PNG pour les arcs
- Pas de framework externe (JS natif seulement)

## Responsive
Mobile : ajustement de la taille des textes, marges réduites.
