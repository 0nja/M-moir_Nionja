# AI Chat Interface

## Intent
Produit conversationnel : montrer l'interface de discussion comme démonstration principale.

Catégorie : Niche & Spécial. Ton : conversationnel, doux, clair, moderne.

## Style
- Bulles asymétriques : utilisateur à droite, assistant à gauche
- Palette neutre chaude avec un accent
- Zone de saisie proéminente en bas
- Réponses formatées avec listes et blocs de code

## Colors
- Mode: light
- Primary: #C2542A
- Secondary: #F5F0EA
- Background: #FAF9F7
- Surface: #FFFFFF
- Text: #1F1D1B
- Text Muted: #6B6560
- Border: #E8E3DC
- Background treatment: plain

## Typography
- Heading font: Inter
- Body font: Inter
- Hero: 48px, weight 600, tracking -0.03em
- H2: 28px, weight 600, tracking -0.01em
- Body: 16px, line-height 1.7
- Case: none
- Détail: Bulles arrondies 18px, code en mono sur fond gris chaud

## Layout
- Container: 1080px
- Hero: split
- Section principale: list
- Espacement entre sections: 88px entre sections
- Grille: conversation en colonne de 720px

## Spacing & Shape
- Border radius: 18px
- Borders: 1px solid #E8E3DC
- Shadows: 0 6px 18px -14px rgba(0,0,0,0.2)

## Animation
- Load: la réponse s'écrit progressivement
- Hover: actions de message (copier, régénérer) qui apparaissent
- Scroll: défilement automatique vers le dernier message

## Components
- Navbar minimale
- Hero avec conversation démonstrative
- Zone de saisie avec suggestions
- Capacités en liste
- Section confidentialité des données
- Tarification
- Pied de page

## Sections Order
1. Navbar minimale
2. Hero avec conversation démonstrative
3. Zone de saisie avec suggestions
4. Capacités en liste
5. Section confidentialité des données
6. Tarification
7. Pied de page

## Do / Don't for AI
**Do:**
- Montrer une conversation réaliste et utile
- Indiquer clairement les limites du modèle
- Permettre de copier chaque réponse

**Don't:**
- Pas de démonstration trompeuse des capacités
- Pas de bulle sans indication d'auteur
- Ne pas cacher la politique de traitement des données

## Responsive
Mobile : conversation pleine largeur, zone de saisie fixe en bas.
