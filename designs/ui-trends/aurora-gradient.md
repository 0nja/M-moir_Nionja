# Aurora Gradient Mesh

## Intent
Landing moderne dont l'identité visuelle repose entièrement sur un dégradé mesh animé.

Catégorie : Tendances UI. Ton : coloré, doux, atmosphérique, contemporain.

## Style
- Trois à quatre taches de couleur floutées à 140px
- Fond clair ou sombre selon la variante, contenu toujours net
- Aucun autre élément décoratif que le dégradé
- Boutons en aplat sombre pour trancher

- Mode: light

- Secondary: #F472B6

- Background treatment: mesh

## Components
- Navbar transparente
- Hero centré sur dégradé
- Trois cartes de bénéfices
- Section preuve sociale

- Pied de page clair

## Sections Order
1. Navbar transparente
2. Hero centré sur dégradé
3. Trois cartes de bénéfices
4. Section preuve sociale
5. CTA sur fond dégradé plus intense
6. Pied de page clair

## Do / Don't for AI
**Do:**
- Flouter fortement les taches pour éviter les bords visibles
- Ajouter un léger grain pour supprimer les bandes
- Poser le texte sur une surface opaque

**Don't:**
- Pas de texte directement sur la zone la plus colorée
- Pas plus de quatre couleurs
- Ne pas animer trop vite le dégradé

## Responsive
Mobile : deux taches seulement, animation désactivée si prefers-reduced-motion.
