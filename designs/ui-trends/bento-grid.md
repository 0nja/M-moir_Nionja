# Bento Grid

## Intent
Présenter beaucoup de fonctionnalités d'un coup d'œil, chacune dans un module dont la taille traduit l'importance.

Catégorie : Tendances UI. Ton : modulaire, dense, organisé, contemporain.

## Style
- Grille 4 colonnes où les modules occupent 1, 2 ou 4 cases
- Chaque module contient un visuel et une phrase courte
- Gouttière constante de 16px
- Fond neutre, modules légèrement plus clairs

## Colors
- Mode: dark
- Primary: #F97316
- Secondary: #27272A
- Background: #09090B
- Surface: #18181B
- Text: #FAFAFA
- Text Muted: #A1A1AA
- Border: #27272A
- Background treatment: plain

## Typography
- Heading font: Inter
- Body font: Inter
- Hero: 56px, weight 700, tracking -0.03em
- H2: 22px, weight 600, tracking -0.01em
- Body: 15px, line-height 1.55
- Case: none
- Détail: Titre de module en 20px, description en 14px gris

## Layout
- Container: 1200px
- Hero: centered
- Section principale: bento
- Espacement entre sections: 96px entre sections
- Grille: 4 colonnes, modules 1x1, 2x1, 2x2

## Spacing & Shape
- Border radius: 18px
- Borders: 1px solid #27272A
- Shadows: aucune

## Animation
- Load: les modules apparaissent en cascade diagonale
- Hover: le module s'éclaircit et son visuel bouge
- Scroll: reveal module par module

## Components
- Navbar simple
- Hero court sur deux lignes
- Grille bento principale
- Second bento de secondaires
- Bandeau de chiffres
- Pied de page compact

## Sections Order
1. Navbar simple
2. Hero court sur deux lignes
3. Grille bento principale
4. Second bento de secondaires
5. Bandeau de chiffres
6. Pied de page compact

## Do / Don't for AI
**Do:**
- Varier les tailles de modules pour créer un rythme
- Garder une gouttière identique partout
- Mettre un seul message par module

**Don't:**
- Pas de module vide pour remplir la grille
- Pas de texte long dans un petit module
- Ne pas casser l'alignement de la grille

## Responsive
Mobile : 1 colonne, l'ordre suit l'importance décroissante des modules.
