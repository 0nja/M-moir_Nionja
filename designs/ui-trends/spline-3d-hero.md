# 3D Spline Hero

## Intent
Produit qui se raconte par un objet 3D manipulable placé au cœur du hero.

Catégorie : Tendances UI. Ton : immersif, moderne, technique, spectaculaire.

## Style
- Objet 3D occupant 60% du hero, réagissant à la souris
- Interface volontairement discrète autour du 3D
- Fond sombre uni pour isoler l'objet
- Éclairage coloré unique sur l'objet

## Colors
- Mode: dark
- Primary: #A78BFA
- Secondary: #312E81
- Background: #0A0A0F
- Surface: #141420
- Text: #F5F5FA
- Text Muted: #9A9AB0
- Border: #22222E
- Background treatment: radial-glow

## Typography
- Heading font: Space Grotesk
- Body font: Inter
- Hero: 54px, weight 700, tracking -0.03em
- H2: 32px, weight 600, tracking -0.02em
- Body: 17px, line-height 1.6
- Case: none
- Détail: Textes courts, la démonstration passe par l'objet 3D

## Layout
- Container: 1200px
- Hero: fullbleed
- Section principale: grid-3
- Espacement entre sections: 120px entre sections
- Grille: hero pleine hauteur, sections classiques ensuite

## Spacing & Shape
- Border radius: 14px
- Borders: 1px solid #22222E
- Shadows: 0 0 100px -40px #A78BFA

## Animation
- Load: l'objet 3D apparaît en rotation lente
- Hover: l'objet suit le curseur avec inertie
- Scroll: l'objet change d'angle au fil du défilement

## Components
- Navbar minimale
- Hero 3D pleine hauteur
- Trois points clés sous le pli
- Section détail avec captures
- Bandeau CTA
- Pied de page sobre

## Sections Order
1. Navbar minimale
2. Hero 3D pleine hauteur
3. Trois points clés sous le pli
4. Section détail avec captures
5. Bandeau CTA
6. Pied de page sobre

## Do / Don't for AI
**Do:**
- Prévoir une image de repli si le 3D ne charge pas
- Limiter le poids de la scène 3D
- Garder l'interface autour très sobre

**Don't:**
- Pas de texte par-dessus l'objet en mouvement
- Pas de scène 3D chargée sur mobile sans repli
- Ne pas ajouter d'autres animations concurrentes

## Responsive
Mobile : le 3D est remplacé par une image ou une vidéo courte en boucle.
