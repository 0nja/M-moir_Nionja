# Grain & Noise Texture

## Intent
Studio ou marque qui veut une image analogique et texturée plutôt que numérique et lisse.

Catégorie : Tendances UI. Ton : texturé, analogique, mat, chaleureux.

## Style
- Overlay de grain SVG à 6% d'opacité sur toute la page
- Couleurs terreuses désaturées
- Images en duotone
- Aucune ombre brillante, tout est mat

## Colors
- Mode: light
- Primary: #B4532A
- Secondary: #DCD3C3
- Background: #EFE9DE
- Surface: #F7F3EA
- Text: #221E1A
- Text Muted: #6B6258
- Border: #D6CDBD
- Background treatment: noise

## Typography
- Heading font: Instrument Serif
- Body font: Inter
- Hero: 68px, weight 400, tracking -0.02em
- H2: 36px, weight 400, tracking -0.01em
- Body: 17px, line-height 1.7
- Case: none
- Détail: Serif fin pour les titres, sans-serif neutre pour le corps

## Layout
- Container: 1120px
- Hero: editorial
- Section principale: cards-2
- Espacement entre sections: 104px entre sections
- Grille: asymétrique, marges inégales

## Spacing & Shape
- Border radius: 4px
- Borders: 1px solid #D6CDBD
- Shadows: aucune

## Animation
- Load: fade 400ms
- Hover: l'image passe du duotone à la couleur
- Scroll: reveal doux

## Components
- Navbar texte simple
- Hero éditorial avec image duotone
- Deux colonnes de projets
- Bloc manifeste
- Galerie texturée
- Pied de page mat

## Sections Order
1. Navbar texte simple
2. Hero éditorial avec image duotone
3. Deux colonnes de projets
4. Bloc manifeste
5. Galerie texturée
6. Pied de page mat

## Do / Don't for AI
**Do:**
- Appliquer le grain en overlay global, pas par élément
- Désaturer légèrement toutes les images
- Garder les ombres absentes

**Don't:**
- Pas de couleur fluo
- Pas d'ombre portée brillante
- Ne pas dépasser 8% d'opacité de grain

## Responsive
Mobile : grain conservé, colonnes empilées.
