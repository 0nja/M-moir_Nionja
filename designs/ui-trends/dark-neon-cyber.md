# Dark Neon Cyber

## Intent
Produit gaming, cybersécurité ou événement tech nocturne. Énergie et tension visuelle.

Catégorie : Tendances UI. Ton : cyberpunk, contrasté, électrique, nocturne.

## Style
- Fond noir avec lignes de circuit fines
- Bordures néon qui émettent une lueur
- Angles coupés en diagonale sur les cartes
- Texte accentué avec glitch occasionnel

## Colors
- Mode: dark
- Primary: #00F0FF
- Secondary: #FF00A8
- Background: #05060A
- Surface: #0C0F18
- Text: #E8FBFF
- Text Muted: #7B8CA6
- Border: #16324A
- Background treatment: grid

- Body font: Inter

- Grille: grille technique visible en fond

## Spacing & Shape
- Border radius: 2px, angles coupés à 12px sur un coin
- Borders: 1px solid #00F0FF

## Animation
- Load: les bordures se dessinent trait par trait
- Hover: glitch court de 150ms
- Scroll: lignes de scan qui traversent la page

## Components
- Navbar angulaire
- Hero pleine largeur avec visuel sombre
- Cartes à angles coupés
- Tableau de statistiques néon
- Compte à rebours
- Pied de page technique

## Sections Order
1. Navbar angulaire

4. Tableau de statistiques néon

## Do / Don't for AI
**Do:**
- Garder le fond très sombre pour maximiser le contraste
- Utiliser exactement deux néons
- Couper les angles de façon cohérente

**Don't:**
- Pas de néon sur les paragraphes
- Pas de coins arrondis classiques
- Ne pas abuser du glitch

## Responsive
Mobile : grille de fond allégée, angles coupés conservés.
