# Y2K Chrome

## Intent
Marque jeune ou drop de mode qui joue la nostalgie de l'an 2000 : métal, reflets, pastilles brillantes.

Catégorie : Rétro & Nostalgie. Ton : brillant, métallique, futuriste-rétro, saturé.

## Style
- Dégradés chromés argent avec reflets bleus
- Boutons en pastille très arrondie avec surbrillance blanche
- Typographie étirée horizontalement
- Étoiles et éclats scintillants en décoration

## Colors
- Mode: light
- Primary: #3D7BFF
- Secondary: #C9D6E8
- Background: #E8EEF6
- Surface: #FFFFFF
- Text: #0B1B33
- Text Muted: #5A6B85
- Border: #B9C7DA
- Background treatment: mesh

## Typography
- Heading font: Orbitron
- Body font: Inter
- Hero: 64px, weight 800, tracking 0.02em
- H2: 34px, weight 700, tracking 0.01em
- Body: 16px, line-height 1.6
- Case: upper
- Détail: Titres avec un liseré blanc et une ombre bleue interne

## Layout
- Container: 1100px
- Hero: centered
- Section principale: cards-2
- Espacement entre sections: 96px entre sections
- Grille: cartes flottantes superposées

## Spacing & Shape
- Border radius: 999px sur les boutons, 20px sur les cartes
- Borders: 1px solid rgba(255,255,255,0.8) en surbrillance haute
- Shadows: 0 12px 24px -12px rgba(61,123,255,0.5), inset 0 1px 0 #FFFFFF

## Animation
- Load: les éléments arrivent avec un léger rebond
- Hover: le reflet se déplace sur le bouton
- Scroll: étoiles scintillantes en parallaxe

- Bandeau d'étoiles scintillantes

## Do / Don't for AI
**Do:**
- Toujours ajouter une surbrillance blanche en haut des éléments
- Utiliser des dégradés à trois arrêts minimum pour le chrome
- Garder le texte lisible malgré les reflets

**Don't:**
- Pas de plat mat
- Pas de palette sombre
- Ne pas mettre de reflet sur les paragraphes

## Responsive
Mobile : cartes empilées, effets de reflet simplifiés pour les performances.
