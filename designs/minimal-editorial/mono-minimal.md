# Monospace Minimal

## Intent
Page personnelle de développeur ou de chercheur. L'esthétique du terminal appliquée à un document sobre.

Catégorie : Minimal & Éditorial. Ton : sobre, technique, discret, textuel.

## Style
- Une seule police monospace pour tout le document
- Corps de texte 14px, interligne généreuse
- Séparateurs faits de tirets ou de traits fins
- Aucune image, uniquement du texte et des liens

## Colors
- Mode: light
- Primary: #0F5132
- Secondary: #E9ECEF
- Background: #FCFCFA
- Surface: #F4F4F1
- Text: #1B1B1B
- Text Muted: #777777
- Border: #DDDDD8
- Background treatment: plain

## Typography
- Heading font: JetBrains Mono
- Body font: JetBrains Mono
- Hero: 32px, weight 700, tracking 0
- H2: 20px, weight 700, tracking 0
- Body: 14px, line-height 1.8
- Case: none
- Détail: Les liens sont préfixés par -> et les sections par ##

## Layout
- Container: 680px
- Hero: editorial
- Section principale: list
- Espacement entre sections: 56px entre sections
- Grille: colonne unique

## Spacing & Shape
- Border radius: 2px
- Borders: 1px solid #DDDDD8
- Shadows: aucune

## Animation
- Load: aucune
- Hover: le lien passe en fond vert clair
- Scroll: aucune

## Components
- En-tête : nom et une ligne de description
- Liste de projets avec année alignée à droite
- Section notes / écrits
- Bloc de contact en texte brut
- Pied de page avec date de dernière mise à jour

## Sections Order
1. En-tête : nom et une ligne de description
2. Liste de projets avec année alignée à droite
3. Section notes / écrits
4. Bloc de contact en texte brut
5. Pied de page avec date de dernière mise à jour

## Do / Don't for AI
**Do:**
- Aligner les dates et les colonnes au caractère près
- Rester sous 680px de largeur
- Écrire court

**Don't:**
- Pas d'image décorative
- Pas de seconde police
- Ne pas ajouter d'animation

## Responsive
Mobile : padding 20px, tailles inchangées, colonnes de dates passées sous le titre.
