# Modern SaaS Landing

## Intent
Landing page pour un produit SaaS B2B. Objectif : conversion vers essai gratuit.
Ton : professionnel, moderne, rassurant.

## Style Keywords
minimalist, spacious, trustworthy, product-focused

## Colors
- Mode: light
- Primary: #2563EB (Bleu royal)
- Secondary: #DBEAFE (Bleu très clair)
- Background: #FFFFFF
- Surface: #F8FAFC
- Text Primary: #0F172A
- Text Muted: #64748B
- Border: #E2E8F0

## Typography
- Heading Font: Inter
- Body Font: Inter
- Scale:
  - Hero: 64px, 700, tracking -0.02em
  - H1: 48px, 700
  - H2: 36px, 600
  - Body: 18px, 400, line-height 1.6

## Layout
- Container: 1200px max-width, center aligned
- Patterns: hero_centered, three_column_grid
- Spacing: 120px between sections

## Spacing & Shape
- Border radius: 12px (cards), 8px (buttons)
- Shadows: 
  - Cards: 0 10px 25px -5px rgba(0, 0, 0, 0.05)
  - Buttons: 0 4px 6px -1px rgba(37, 99, 235, 0.2)

## Animation
- Load: Fade in translate-y 20px
- Hover: Buttons slightly lift (-2px) and shadow increases

## Components
- Navigation: Sticky top, logo left, links center, CTA right
- Hero: Centered headline, subtitle, dual CTA (primary/secondary), followed by a large app mockup screenshot
- Features: 3 column grid of cards with subtle icons
- Pricing: 3 tiers, center tier highlighted

## Do / Don't for AI
**Do:**
- Utiliser abondamment l'espace blanc (whitespace)
- S'assurer que le bleu primaire (#2563EB) ressort bien comme élément d'action
- Les bordures doivent être très discrètes (gris très clair)

**Don't:**
- Pas d'images d'arrière-plan complexes
- Pas de typographie fantaisiste
- Ne pas assombrir les textes secondaires, les garder lisibles (#64748B)

## Sections Order
1. Navigation
2. Hero
3. Dashboard Mockup Image
4. Features
5. CTA Footer
