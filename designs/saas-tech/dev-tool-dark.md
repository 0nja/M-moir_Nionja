# Dark Developer Tool

## Intent
Présenter un outil CLI / infra à un public technique. Crédibilité par la densité d'information et le code visible dès le hero.

Catégorie : SaaS & Tech. Ton : technique, sombre, dense, crédible.

## Style
- Fond #0A0A0A, surfaces #111111 séparées par des bordures fines
- Bloc de code réel dans le hero, pas une illustration
- Accent vert menthe utilisé avec parcimonie
- Typographie mono pour tout ce qui est technique

## Colors
- Mode: dark
- Primary: #4ADE80
- Secondary: #134E29
- Background: #0A0A0A
- Surface: #141414
- Text: #FAFAFA
- Text Muted: #8B8B8B
- Border: #262626
- Background treatment: grid

## Typography
- Heading font: Inter
- Body font: Inter
- Hero: 56px, weight 700, tracking -0.02em
- H2: 32px, weight 600, tracking -0.01em
- Body: 16px, line-height 1.65
- Case: none
- Détail: JetBrains Mono 14px pour le code, les badges et les labels de section

## Layout
- Container: 1140px
- Hero: split
- Section principale: grid-3
- Espacement entre sections: 96px entre sections
- Grille: grille de fond 40px en rgba(255,255,255,0.03)

## Spacing & Shape
- Border radius: 8px
- Borders: 1px solid #262626 sur chaque surface
- Shadows: aucune ombre, la séparation se fait par la bordure

## Animation
- Load: fade 200ms, curseur qui clignote dans le bloc de code
- Hover: bordure qui passe à #4ADE80
- Scroll: aucune animation lourde, tout reste immédiat

## Components
- Navbar fine avec compteur de stars GitHub
- Hero deux colonnes : texte à gauche, terminal à droite
- Commande d'installation copiable
- Features 3 colonnes en cartes bordées
- Comparatif technique en tableau
- Footer dense multi-colonnes

## Sections Order
1. Navbar fine avec compteur de stars GitHub
2. Hero deux colonnes : texte à gauche, terminal à droite
3. Commande d'installation copiable
4. Features 3 colonnes en cartes bordées
5. Comparatif technique en tableau
6. Footer dense multi-colonnes

## Do / Don't for AI
**Do:**
- Afficher du code réel et syntaxiquement correct
- Utiliser la mono pour les versions, commandes et labels
- Garder un contraste élevé du texte principal

**Don't:**
- Pas d'illustration 3D ni de mascotte
- Pas de dégradé coloré sur le fond
- Ne jamais mettre de vert sur de grandes surfaces

## Responsive
Mobile : le terminal passe sous le texte, scroll horizontal autorisé dans les blocs de code.
