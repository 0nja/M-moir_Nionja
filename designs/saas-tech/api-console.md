# API & Console Product

## Intent
Vendre une API en montrant directement la requête et la réponse. La page ressemble à la doc du produit.

Catégorie : SaaS & Tech. Ton : technique, structuré, démonstratif, sobre.

## Style
- Interface en panneaux avec en-têtes d'onglets
- Couleurs de syntaxe cohérentes dans tous les blocs
- Fond clair, panneaux de code sombres
- Densité assumée, peu d'espace perdu

## Colors
- Mode: light
- Primary: #0F766E
- Secondary: #CCFBF1
- Background: #FFFFFF
- Surface: #F6F8FA
- Text: #111827
- Text Muted: #6B7280
- Border: #D9DEE4
- Background treatment: plain

## Typography
- Heading font: Inter
- Body font: Inter
- Hero: 48px, weight 700, tracking -0.02em
- H2: 28px, weight 600, tracking 0
- Body: 16px, line-height 1.7
- Case: none
- Détail: IBM Plex Mono 13px dans tous les panneaux, méthodes HTTP en pastilles colorées

## Layout
- Container: 1280px
- Hero: split
- Section principale: table
- Espacement entre sections: 80px entre sections
- Grille: sidebar 240px + contenu

## Spacing & Shape
- Border radius: 6px
- Borders: 1px solid #D9DEE4
- Shadows: 0 1px 2px rgba(0,0,0,0.04)

## Animation
- Load: aucune, la page apparaît instantanément
- Hover: surlignage de ligne dans les tableaux
- Scroll: sommaire latéral qui suit la section active

## Components
- Navbar avec recherche et sélecteur de version
- Hero deux colonnes : promesse à gauche, requête/réponse à droite
- Onglets de langages (cURL, Python, JS)
- Tableau des endpoints
- Section limites et quotas
- Footer développeur avec statut de l'API

## Sections Order
1. Navbar avec recherche et sélecteur de version
2. Hero deux colonnes : promesse à gauche, requête/réponse à droite
3. Onglets de langages (cURL, Python, JS)
4. Tableau des endpoints
5. Section limites et quotas
6. Footer développeur avec statut de l'API

## Do / Don't for AI
**Do:**
- Montrer une vraie paire requête/réponse
- Colorer les méthodes HTTP de façon constante
- Prévoir un bouton copier sur chaque bloc

**Don't:**
- Pas de marketing vague sans exemple technique
- Pas d'animation qui retarde la lecture
- Ne pas mélanger plusieurs polices mono

## Responsive
Mobile : sommaire en accordéon, panneaux de code en scroll horizontal.
