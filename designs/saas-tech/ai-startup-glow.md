# AI Startup Glow

## Intent
Startup IA en levée de fonds. Donner une impression de puissance et de nouveauté immédiate.

Catégorie : SaaS & Tech. Ton : futuriste, lumineux, énergique, technologique.

## Style
- Halos violet/cyan flous derrière le contenu
- Bordures lumineuses sur les cartes
- Démonstration de prompt animée dans le hero
- Beaucoup de noir pour faire ressortir les lueurs

## Colors
- Mode: dark
- Primary: #8B5CF6
- Secondary: #22D3EE
- Background: #050508
- Surface: #0E0E16
- Text: #FFFFFF
- Text Muted: #9BA1AE
- Border: #1E1E2E
- Background treatment: aurora

## Typography
- Heading font: Inter
- Body font: Inter
- Hero: 68px, weight 800, tracking -0.03em
- H2: 38px, weight 700, tracking -0.02em
- Body: 18px, line-height 1.6
- Case: none
- Détail: Titre principal en dégradé violet→cyan sur le mot clé

## Layout
- Container: 1200px
- Hero: centered
- Section principale: bento
- Espacement entre sections: 128px entre sections
- Grille: bento asymétrique

## Spacing & Shape
- Border radius: 16px
- Borders: 1px solid rgba(139,92,246,0.25)
- Shadows: 0 0 80px -30px #8B5CF6

## Animation
- Load: texte qui s'écrit caractère par caractère dans le prompt
- Hover: scale 1.02 + intensification du halo
- Scroll: les halos se déplacent lentement en parallaxe

## Components
- Navbar avec badge de levée de fonds
- Hero centré avec champ de prompt animé
- Bento de capacités du modèle
- Benchmarks en barres
- Logos d'entreprises utilisatrices
- CTA avec liste d'attente

## Sections Order
1. Navbar avec badge de levée de fonds
2. Hero centré avec champ de prompt animé
3. Bento de capacités du modèle
4. Benchmarks en barres
5. Logos d'entreprises utilisatrices
6. CTA avec liste d'attente

## Do / Don't for AI
**Do:**
- Flouter fortement les halos (blur 120px minimum)
- Limiter le dégradé à un ou deux mots du titre
- Garder les corps de texte en blanc cassé lisible

**Don't:**
- Pas de dégradé sur les paragraphes
- Pas plus de deux couleurs de halo
- Ne pas empiler les effets jusqu'à l'illisibilité

## Responsive
Mobile : un seul halo conservé, bento empilé, hero 42px.
