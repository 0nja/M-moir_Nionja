# Refined Product (Linear-like)

## Intent
Produit logiciel haut de gamme pour équipes techniques. Le raffinement des détails est le principal argument.

Catégorie : SaaS & Tech. Ton : raffiné, sombre, subtil, premium.

## Style
- Fond bleu-noir très désaturé avec une lueur violette diffuse en haut
- Bordures en dégradé (1px, du blanc 12% au transparent)
- Micro-contrastes : chaque surface est légèrement plus claire que le fond
- Texte titre en dégradé blanc vers gris

## Colors
- Mode: dark
- Primary: #7C6BF5
- Secondary: #2A2545
- Background: #08080C
- Surface: #101018
- Text: #F7F8F8
- Text Muted: #8A8F98
- Border: #1F1F2A
- Background treatment: radial-glow

## Typography
- Heading font: Inter
- Body font: Inter
- Hero: 60px, weight 600, tracking -0.04em
- H2: 34px, weight 600, tracking -0.02em
- Body: 17px, line-height 1.6
- Case: none
- Détail: Tracking très négatif sur les titres, weight 600 jamais 800

## Layout
- Container: 1080px
- Hero: centered
- Section principale: bento
- Espacement entre sections: 112px entre sections
- Grille: bento 2/3 + 1/3

## Spacing & Shape
- Border radius: 10px
- Borders: 1px solid rgba(255,255,255,0.08)
- Shadows: 0 0 60px -20px rgba(124,107,245,0.4)

## Animation
- Load: fade-up 16px, easing cubic-bezier(0.16,1,0.3,1), durée 600ms
- Hover: lueur qui suit le curseur sur les cartes
- Scroll: parallaxe très légère sur la lueur de fond

## Components
- Navbar translucide avec blur
- Hero centré + capture produit inclinée
- Bento de fonctionnalités
- Section changelog
- Témoignages sur une ligne
- Footer minimal

## Sections Order
1. Navbar translucide avec blur
2. Hero centré + capture produit inclinée
3. Bento de fonctionnalités
4. Section changelog
5. Témoignages sur une ligne
6. Footer minimal

## Do / Don't for AI
**Do:**
- Rester sur des écarts de luminosité très faibles entre surfaces
- Soigner les états focus et hover, ils font le style
- Utiliser le violet uniquement en lueur et en accent

**Don't:**
- Pas de noir pur ni de blanc pur
- Pas d'ombre portée dure
- Ne pas dépasser weight 600 sur les titres

## Responsive
Mobile : bento en une colonne, lueur réduite, capture produit redressée.
