# Open Source Project

## Intent
Page d'accueil d'un projet open source. Faire installer, contribuer, et donner une star.

Catégorie : SaaS & Tech. Ton : neutre, factuel, communautaire, direct.

## Style
- Palette neutre grise avec un seul accent
- Badges (version, licence, CI) sous le titre
- Commande d'installation immédiatement visible
- Avatars de contributeurs en mosaïque

## Colors
- Mode: light
- Primary: #24292F
- Secondary: #DDF4FF
- Background: #FFFFFF
- Surface: #F6F8FA
- Text: #1F2328
- Text Muted: #656D76
- Border: #D0D7DE
- Background treatment: plain

## Typography
- Heading font: Inter
- Body font: Inter
- Hero: 44px, weight 700, tracking -0.02em
- H2: 26px, weight 600, tracking 0
- Body: 16px, line-height 1.6
- Case: none
- Détail: Mono 13px pour les commandes, badges SVG 20px de haut

## Layout
- Container: 1012px
- Hero: centered
- Section principale: list
- Espacement entre sections: 72px entre sections
- Grille: colonne unique étroite

## Spacing & Shape
- Border radius: 6px
- Borders: 1px solid #D0D7DE
- Shadows: aucune

## Animation
- Load: aucune
- Hover: fond gris clair sur les lignes cliquables
- Scroll: aucune

## Components
- Navbar minimale avec lien GitHub
- Hero centré avec badges
- Bloc d'installation copiable
- Exemple minimal en code
- Liste de fonctionnalités à puces
- Mosaïque de contributeurs
- Footer licence

## Do / Don't for AI
**Do:**
- Mettre l'installation au-dessus de la ligne de flottaison
- Rester factuel, pas de superlatifs marketing
- Afficher clairement la licence

**Don't:**
- Pas d'animation ni de dégradé
- Pas de container large, la lecture prime
- Ne pas cacher les limitations connues

## Responsive
Mobile : tout en une colonne, commandes en scroll horizontal.
