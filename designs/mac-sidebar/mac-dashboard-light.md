# Mac Dashboard Light

## Intent
Interface web reprenant les codes visuels d'une app macOS claire pour un SaaS.

Catégorie : Mac Sidebar & Dashboards. Ton : macOS, dashboard, clair, translucide, fontawesome.

## Style
- Sidebar avec 3 points macOS (rouge, jaune, vert)
- Style clair et épuré, fond gris très clair
- Icônes FontAwesome régulières (fa-regular)
- Fenêtre flottante avec ombre douce

## Colors
- Mode: light
- Primary: #007AFF
- Secondary: #34C759
- Background: #F2F2F7
- Surface: #FFFFFF
- Text: #000000
- Text Muted: #8E8E93
- Border: #E5E5EA
- Background treatment: plain

## Typography
- Heading font: Inter
- Body font: Inter
- Hero: 24px, weight 600, tracking 0
- H2: 18px, weight 600, tracking 0
- Body: 14px, line-height 1.5
- Case: none
- Détail: Texte très lisible, fort contraste.

## Layout
- Container: 100%
- Hero: none
- Section principale: grid-3
- Espacement entre sections: 24px entre sections
- Grille: sidebar 240px + contenu

## Spacing & Shape
- Border radius: 10px
- Borders: 1px solid #E5E5EA
- Shadows: 0 10px 30px rgba(0,0,0,0.1)

## Animation
- Load: scale up depuis 0.98
- Hover: surlignage bleu macOS sur les menus
- Scroll: scroll natif

## Components
- Sidebar avec points rouge/jaune/vert et menu FontAwesome
- Header avec barre de recherche (fa-search)
- Graphiques et cartes de données
- Liste d'utilisateurs avec avatars et icônes

## Sections Order
1. Sidebar avec points rouge/jaune/vert et menu FontAwesome
2. Header avec barre de recherche (fa-search)
3. Graphiques et cartes de données
4. Liste d'utilisateurs avec avatars et icônes

## Do / Don't for AI
**Do:**
- Points macOS de 12px de diamètre
- Icônes FontAwesome alignées au centre
- Utiliser le bleu macOS pour les actions principales

**Don't:**
- Zéro emoji
- Pas de bordures épaisses
- Ne pas utiliser de couleurs fluo

## Responsive
Mobile : sidebar cachée, header fixe.
