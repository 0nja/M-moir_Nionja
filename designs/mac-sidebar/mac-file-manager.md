# Mac File Manager

## Intent
Application de gestion de fichiers ou de cloud storage avec une vue native.

Catégorie : Mac Sidebar & Dashboards. Ton : finder, cloud, fichiers, macos, fontawesome.

## Style
- Barre latérale translucide (vibrancy) avec points macOS
- Vue grille avec dossiers et icônes de fichiers (FontAwesome)
- Barre d'outils supérieure pour l'affichage et la recherche
- Sélection bleue typique de macOS

## Colors
- Mode: light
- Primary: #007AFF
- Secondary: #5856D6
- Background: #FFFFFF
- Surface: #F2F2F7
- Text: #000000
- Text Muted: #8E8E93
- Border: #D1D1D6
- Background treatment: plain

## Typography
- Heading font: Inter
- Body font: Inter
- Hero: 16px, weight 500, tracking 0
- H2: 14px, weight 500, tracking 0
- Body: 13px, line-height 1.4
- Case: none
- Détail: Petite typographie pour simuler le Finder.

## Layout
- Container: 100%
- Hero: none
- Section principale: grid-5
- Espacement entre sections: 20px
- Grille: sidebar 200px + contenu principal grille

## Spacing & Shape
- Border radius: 10px
- Borders: 1px solid #D1D1D6
- Shadows: 0 10px 30px rgba(0,0,0,0.1)

## Animation
- Load: fade simple
- Hover: l'icône de fichier se grise légèrement (fa-folder-open)
- Scroll: standard

## Components
- Sidebar avec contrôles macOS et icônes FontAwesome (fa-desktop, fa-download, fa-file)
- Barre d'outils (fa-th-large, fa-list)
- Grille de fichiers principale (grandes icônes fa-folder bleu clair)
- Barre d'état en bas

## Sections Order
1. Sidebar avec contrôles macOS et icônes FontAwesome (fa-desktop, fa-download, fa-file)
2. Barre d'outils (fa-th-large, fa-list)
3. Grille de fichiers principale (grandes icônes fa-folder bleu clair)
4. Barre d'état en bas

## Do / Don't for AI
**Do:**
- Colorer les dossiers FontAwesome en bleu (#007AFF)
- Points macOS alignés parfaitement en haut à gauche
- Cadrer l'interface dans une fenêtre avec ombre portée

**Don't:**
- Pas d'emojis
- Pas de typographie marketing massive
- Pas de dégradés multicolores

## Responsive
Mobile : vue liste uniquement, pas de vue grille.
