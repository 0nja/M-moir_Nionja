# File Manager Sidebar

## Intent
Interface de gestion de fichiers ou de cloud storage avec sidebar de navigation et vue principale en grille.

Catégorie : Mac Sidebar & Dashboards. Ton : finder, files, sidebar, light, fontawesome.

## Style
- Sidebar translucide avec raccourcis FontAwesome (Bureau, Téléchargements)
- Points macOS en haut à gauche
- Vue grille avec grandes icônes de dossiers FontAwesome
- Barre d'outils supérieure

## Colors
- Mode: light
- Primary: #007AFF
- Secondary: #5856D6
- Background: #FFFFFF
- Surface: #F2F2F7
- Text: #000000

- Border: #D1D1D6
- Background treatment: plain

## Typography

- Body font: Inter

## Spacing & Shape

## Animation

## Components
- Sidebar avec points macOS et icônes FontAwesome par emplacement
- Toolbar supérieure (fa-th-large, fa-list, fa-search)
- Grille principale de fichiers et dossiers colorés
