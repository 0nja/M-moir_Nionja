# Mail Client Sidebar

## Intent
Interface de messagerie structurée en 3 zones distinctes avec sidebar, liste et vue email.

Catégorie : Mac Sidebar & Dashboards. Ton : mail, sidebar, 3-colonnes, light, fontawesome.

## Style
- Sidebar (dossiers) + liste des messages + vue détaillée
- Points macOS dans la première colonne
- Chaque dossier avec icône FontAwesome
- Bulles de couleur pour les labels

## Colors
- Mode: light
- Primary: #007AFF
- Secondary: #5856D6
- Background: #FFFFFF
- Surface: #F2F2F7
- Text: #000000
- Text Muted: #8E8E93
- Border: #C6C6C8
- Background treatment: plain

## Typography
- Heading font: Inter
- Body font: Inter
- Hero: 16px, weight 600, tracking 0
- H2: 14px, weight 500, tracking 0
- Body: 14px, line-height 1.4
- Case: none
- Détail: Compacte et lisible.

## Layout
- Container: 100%
- Hero: none
- Section principale: none
- Espacement entre sections: 0
- Grille: sidebar 200px + liste 280px + vue email 1fr

## Spacing & Shape
- Border radius: 0
- Borders: 1px solid #C6C6C8
- Shadows: none

## Animation
- Load: instantané
- Hover: ligne de mail surlignée en bleu pâle
- Scroll: indépendant par colonne

## Components
- Sidebar dossiers avec points macOS (fa-inbox, fa-paper-plane)
- Liste de messages avec aperçu
- Vue email avec toolbar FontAwesome
- Bouton Nouveau message

## Sections Order
1. Sidebar dossiers avec points macOS (fa-inbox, fa-paper-plane)
2. Liste de messages avec aperçu
3. Vue email avec toolbar FontAwesome
4. Bouton Nouveau message

## Do / Don't for AI
**Do:**
- Points macOS dans la première colonne
- Scroll indépendant pour chaque colonne
- FontAwesome pour les dossiers et actions

**Don't:**
- Aucun emoji
- Pas de scroll global de la page
- Pas d'images d'illustration

## Responsive
Mobile : afficher une colonne à la fois.
