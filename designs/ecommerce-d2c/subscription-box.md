# Subscription Box

## Intent
Box par abonnement : expliquer le principe, montrer le contenu, lever les freins à l'engagement.

Catégorie : E-commerce & D2C. Ton : joyeux, pédagogique, coloré, rassurant.

## Style
- Illustrations et photos de la box ouverte
- Palette vive à trois couleurs
- Étapes numérotées avec grandes icônes
- Formule d'abonnement en cartes comparables

## Colors
- Mode: light

- Background treatment: mesh

## Spacing & Shape

## Animation
- Load: rebond léger sur la box
- Hover: la carte de formule se soulève
- Scroll: les étapes se remplissent

## Do / Don't for AI
**Do:**
- Dire clairement que l'abonnement est résiliable à tout moment
- Montrer le contenu réel d'une box
- Afficher le prix par mois sans ambiguïté

**Don't:**
- Pas d'engagement caché
- Pas de contenu de box non représentatif
- Ne pas complexifier les formules

## Responsive
Mobile : formules empilées, étapes verticales.
