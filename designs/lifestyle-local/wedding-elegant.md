# Wedding Elegant

## Intent
Site de mariage : informations pratiques pour les invités et RSVP en ligne.

Catégorie : Lifestyle & Local. Ton : romantique, délicat, personnel, doux.

## Style
- Palette blush, ivoire et vert eucalyptus
- Police script pour les prénoms, serif pour le reste
- Illustrations florales aquarelle en bordure
- Compte à rebours discret vers la date

## Do / Don't for AI
**Do:**
- Rendre le RSVP très simple (trois champs maximum)
- Donner l'adresse exacte et les accès
- Garder la symétrie centrale

**Don't:**
- Pas de script pour les paragraphes
- Pas de musique automatique
- Ne pas oublier le code vestimentaire s'il y en a un

## Responsive
Mobile : programme en frise verticale, RSVP pleine largeur.
