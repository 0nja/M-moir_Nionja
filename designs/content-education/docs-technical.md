# Technical Documentation

## Intent
Documentation d'un produit technique : trouver l'information en moins de trois clics.

Catégorie : Contenu & Éducation. Ton : structuré, lisible, technique, navigable.

## Style
- Navigation latérale gauche arborescente
- Sommaire de page à droite qui suit la lecture
- Blocs de code avec onglets de langage
- Encadrés colorés pour note, avertissement et danger

## Colors
- Mode: light
- Primary: #4F46E5
- Secondary: #EEF2FF
- Background: #FFFFFF
- Surface: #F8FAFC
- Text: #0F172A
- Text Muted: #64748B
- Border: #E2E8F0
- Background treatment: plain

## Typography
- Heading font: Inter
- Body font: Inter
- Hero: 36px, weight 700, tracking -0.02em
- H2: 24px, weight 600, tracking -0.01em
- Body: 16px, line-height 1.7
- Case: none
- Détail: Code en JetBrains Mono 14px, code inline sur fond gris arrondi

## Layout
- Container: 1440px
- Hero: sidebar
- Section principale: list
- Espacement entre sections: 40px entre sections
- Grille: sidebar 260px + contenu 760px + sommaire 220px

## Spacing & Shape
- Border radius: 8px
- Borders: 1px solid #E2E8F0
- Shadows: aucune

## Animation
- Load: aucune
- Hover: surlignage des entrées de navigation
- Scroll: l'entrée active du sommaire se met à jour

## Components
- Barre supérieure avec recherche et sélecteur de version
- Navigation latérale arborescente
- Fil d'Ariane
- Contenu avec titres ancrés
- Blocs de code à onglets
- Encadrés note / attention / danger
- Navigation précédent / suivant
- Sommaire latéral droit

## Do / Don't for AI
**Do:**
- Ancrer chaque titre avec un lien copiable
- Fournir une recherche rapide au clavier
- Indiquer la version de la documentation

**Don't:**
- Pas de contenu caché derrière des onglets non indexables
- Pas d'animation qui gêne la lecture
- Ne pas dépasser 760px pour la colonne de texte

## Responsive
Mobile : navigation en panneau coulissant, sommaire en accordéon en haut.
